yukle-py ("the API Client") is a private command-line tool operated by the owner of the YouTube channels listed on the home page ("the owner"). It runs only on the owner's computer and is used only to manage those channels. It is not offered, sold or distributed to anyone else.

Use of YouTube API Services

The API Client uses YouTube API Services. By using it, users agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the API Client

The only user is the owner of the channels. Each channel belongs to a Google account the owner controls. No other person signs in to the API Client.

Information accessed

After the owner signs in with Google (OAuth 2.0), the API Client accesses, for the owner's own channels only:

  • channel information (channel ID, title, description, keywords, banner);
  • the owner's videos' metadata (title, description, tags, category, privacy status, publish time), thumbnails and caption tracks;
  • YouTube Analytics reports for the owner's channels (views, watch time, average view duration, subscribers gained, traffic sources).

Requested scopes: youtube.upload, youtube.force-ssl, youtube.readonly, yt-analytics.readonly.

How the information is used

  • to upload videos the owner has prepared and approved to the owner's channels;
  • to set thumbnails, captions and metadata on the owner's videos and update the owner's channel details;
  • to read analytics about the owner's channels to plan future videos.

Google user data is used only to provide these features. It is not used for advertising, not sold, not transferred to data brokers or information resellers, and not used to train artificial intelligence or machine learning models.

Storage and protection

  • OAuth tokens are stored only on the owner's computer, in local files that are excluded from any backup or sharing and are never published.
  • Upload results (video ID, upload time) are stored locally in the owner's project files.
  • Analytics figures are kept locally as notes about the owner's channels. Data obtained from YouTube API Services is refreshed or deleted within 30 days.
  • All communication with Google uses HTTPS. There is no server or database operated for the API Client, and no cookies or tracking technologies are used.

Sharing

Information is not shared, transferred or disclosed to any third party. It is sent only to Google/YouTube through the official YouTube API Services to perform the actions above.

Retention, revocation and deletion

Access can be revoked at any time on the Google security settings page. After revocation, the locally stored tokens and any stored API data are deleted within 7 days. Deletion can also be requested at the contact address below.

Changes

If the way the API Client uses Google user data changes, this page will be updated and the date above will change.
